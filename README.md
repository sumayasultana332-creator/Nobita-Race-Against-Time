 # Nobita: Race Against Time

A 3D third-person time-attack treasure hunt desktop game developed using **Godot Engine 4.x**, **C++ (GDExtension)**, and an embedded **SQLite3** relational database.

## Documentation
* [Project Proposal (PDF)](./Nobita_Race%20Against%20Time%20-%20Google%20Docs.pdf)

## Tech Stack
* **Engine:** Godot Engine 4.x
* **Backend & Logic:** C++17 (GDExtension), GDScript
* **Database:** Embedded SQLite3
* **3D Assets & Animations:** Adobe Mixamo
